# TennisAI Core Product Scope V1

## Initial input

MP4/MOV training video, fixed camera behind the baseline, singles, two players,
manually selected surface, and controlled camera configuration.

## Core outputs

Session metadata, rally boundaries, rally clips, ball track, bounces, contacts,
player associations, shot labels, court zones, confidence, metrics, tactical
patterns and coaching input.

## Outside the MVP

Match scoring, doubles, universal camera support, spin measurement, radar-grade
speed, validated XYZ, official line calling, automatic surface recognition and a
mobile app.
