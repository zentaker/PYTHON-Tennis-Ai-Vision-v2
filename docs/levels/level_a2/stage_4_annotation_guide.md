# Anotar eventos — Nivel A2

La aplicación abre el video ya preparado. No necesitas cargar archivos ni configurar
nada.

1. Navega hasta el impacto con `-1`, `+1`, las flechas o la tira de imágenes.
2. Para un evento de un solo frame, pulsa directamente el botón del evento.
3. Para un impacto de varios frames, pulsa **Marcar inicio**, avanza hasta el último
   frame y pulsa **Marcar fin**.
4. Pulsa el botón del evento correspondiente.
5. Revisa la lista; puedes editar, eliminar o deshacer.
6. Cuando termines, pulsa **Finalizar y guardar anotación**.

Usa **Comparar impacto**, zoom y **Mostrar pelota trackeada** cuando necesites distinguir
el frame exacto. No adivines: ante una duda, usa las opciones indeterminadas o un rango
corto.
