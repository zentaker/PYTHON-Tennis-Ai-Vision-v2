# ADRs - Architecture Decision Records

Una decision tecnica relevante, un archivo. Los ADRs iniciales de Stage 0 quedan en estado `Propuesta` hasta aprobacion humana.

- ADR-0008: `0008-captura-calibracion-web-local.md`

## Flujo

1. El agente redacta una propuesta.
2. El usuario revisa.
3. Si se acepta, se cambia `Status` a `Aceptada`.
4. Si se reemplaza, se enlaza el ADR nuevo.
