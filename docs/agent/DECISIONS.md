# Durable decisions

- GitHub and `docs/agent/` are the coordination memory between architecture review and Codex.
- Player-aware perception is a backend-neutral pipeline: detector → tracker → pose → foot anchor → court projection → contact audit → biomechanics.
- The mock backend is the only executable backend in this preparation task.
- OpenMMLab integration is lazy and configuration-driven; weights are external and never downloaded at import/build time.
- Human event observations are evaluation gates, not model inputs, unless explicitly marked ground truth.
- A GPU provider must pass `docs/ops/GPU_PROVIDER_ACCEPTANCE_GATE.md` before adoption.
