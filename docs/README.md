# Documentacion viva

La documentacion de este proyecto es parte del producto. Cada etapa debe dejar evidencia suficiente para que otra persona pueda continuar sin depender del chat.

## Indice

- Roadmap general: `../ROADMAP.md`
- Stage 0: `stages/stage_0/STAGE_0.md`
- Plantilla de etapa: `stages/_template.md`
- Decisiones tecnicas: `decisions/`
- Friccion: `friction/FRICTION_LOG.md`
- Validacion: `validation/VALIDATION_FRAMEWORK.md`
- Protocolo del agente: `agent_protocol/AGENT_PROTOCOL.md`
- Reportes finales: `reports/`

## Reglas

- Una decision tecnica relevante se documenta como ADR.
- Una friccion mayor a 15 minutos se registra.
- Un gate solo se cierra con evidencia y validacion humana explicita.
- No se escriben secretos en el repositorio.
