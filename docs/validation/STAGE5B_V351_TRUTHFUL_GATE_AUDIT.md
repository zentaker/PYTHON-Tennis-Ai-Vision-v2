# Stage 5B v3.5.1 truthful Gate D and Gate A audit

The prior V3.5 implementation was rejected: Gate D was unconditional, anomalous
measurements were not downweighted, V3.4 nodes were reused, and residual/visual
evidence was incomplete. The V3.5.1 rerun applies explicit usability, weights and
sigma values, evaluates every declared event frame, builds new node candidates,
retains multiple global hypotheses, and publishes 314 non-empty residual rows.

Gate D is dynamic and the run is measurement-limited at Gate A. Gate B is not
executed and no final XYZ is generated. All visuals use frame-indexed observation
and candidate data from the real fixture track.
