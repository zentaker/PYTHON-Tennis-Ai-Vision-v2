# Agent operating contract

GitHub is the shared project memory. Every task works on an `agent/*` branch and
never modifies `main` directly. Codex updates the coordination state files before
finishing and never asks the user to copy logs or routes.

Do not use mouse/browser automation, add a cloud provider before its friction gate,
or present an ungated stage as validated. Human observations are evaluation unless
explicitly declared ground truth. Do not reopen closed stages without reproducible
evidence, hide blockers, fabricate metrics/costs/tests, or replace real results with
placeholders. Keep coordination files small and current.
